# Contributing to Guarani LLC Open-Source Projects

Thank you for your interest in contributing to Guarani LLC open-source repositories.

## Reporting Bugs and Feature Requests

- **Bug reports and feature requests:** open an issue in the relevant repository under [github.com/guarani-llc](https://github.com/guarani-llc) using the GitHub issue tracker.
- **Security vulnerabilities:** do not use public issues. Follow our [Security Policy](https://github.com/guarani-llc/.github/blob/main/SECURITY.md) and use GitHub Private Vulnerability Reporting or email `sylvain@guarani-llc.com`.

## Development and Pull Request Process

1. Fork the repository and create a branch from `main`.
2. Ensure all automated tests and linters pass locally before opening a pull request.
3. Add or update unit tests for any new behavior or bug fix.
4. Ensure GitHub Actions CI and CodeQL static analysis pass on your pull request.
5. All contributions are licensed under the repository's declared license (`MIT` for `guarani-verify-action`).
