# Security Policy

Guarani LLC takes the security of Guarani AI (Guarani Verify, Guarani Mesh, and Guarani Mobile CI) and our open-source integrations seriously.

## Supported Versions

| Component | Version | Supported |
| --- | --- | --- |
| `guarani-llc/guarani-verify-action` | `v1.0.x` | Yes |
| Guarani AI Platform (Verify, Mesh, Mobile CI) | `v1 (private beta)` | Yes |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please use one of the following private channels:

1. **GitHub Private Vulnerability Reporting (Preferred for GitHub repositories):**
   Open the **Security** tab of the affected repository under [github.com/guarani-llc](https://github.com/guarani-llc) and click **Report a vulnerability** to submit a private advisory directly to our security team.
2. **Direct Email:**
   Send a report to **[sylvain@guarani-llc.com](mailto:sylvain@guarani-llc.com)**.
   See also our RFC 9116 security manifest at [https://guarani-llc.com/.well-known/security.txt](https://guarani-llc.com/.well-known/security.txt).

### What to Include

To help us triage and resolve the issue quickly, please include:
- The affected component, repository, or endpoint
- Step-by-step instructions or a minimal proof-of-concept to reproduce the issue
- The configuration or environment required to trigger the behavior
- The potential security impact you observed

## Response Timeline and Disclosure

- **Initial acknowledgment:** within 48 hours of receipt
- **Triage and severity assessment:** within 5 business days
- **Coordinated disclosure:** once a fix is released and verified, we credit reporters in our GitHub Security Advisories (GHSA) and CVE records unless anonymity is requested.
